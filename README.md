# Cheeko-Game

Cheeko & Fox is a small browser runner set on a storybook forest trail.

## Run locally

Serve this folder over HTTP, then open the local address in a browser. The page loads Three.js from jsDelivr.

```powershell
python -m http.server 8000
```

## Controls

- Left / Right arrows or A / D: change lanes
- Space or Up: jump
- Down: slide
- P: pause

The supplied forest reference and Blender render are in `assets/`.
